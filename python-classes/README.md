# Python - Classes and Objects

This project covers Object-Oriented Programming (OOP) concepts in Python, focusing on classes, objects, attributes (public and private), methods, properties (getters and setters), data validation, and special methods.

## Files

| File | Description |
| --- | --- |
| `0-square.py` | Empty class `Square` that defines a square. |
| `1-square.py` | Class `Square` that defines a square with a private instance attribute `size`. |
| `2-square.py` | Class `Square` with validation for the `size` attribute (`TypeError` and `ValueError`). |
| `3-square.py` | Class `Square` with public instance method `def area(self):` to calculate area. |
| `4-square.py` | Class `Square` with getter and setter properties for `size`. |
| `5-square.py` | Class `Square` with public instance method `def my_print(self):` to print the square using `#`. |
| `6-square.py` | Class `Square` with private attribute `position` and formatted printing based on coordinates. |
| `100-singly_linked_list.py` | Classes `Node` and `SinglyLinkedList` with sorted insertion in ascending order. |
| `101-square.py` | Class `Square` with `__str__` representation matching `my_print()` behavior. |
| `102-square.py` | Class `Square` with comparison operators (`==`, `!=`, `<`, `<=`, `>`, `>=`) based on area. |
| `103-magic_class.py` | Class `MagicClass` that matches specified Python bytecode. |
